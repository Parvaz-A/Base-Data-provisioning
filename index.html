Audio Library

Upload raw clips once, here. Every announcement in Audio Archive — next-station, final-stop, welcome, via-station, and each special announcement — is built afterwards by combining clips from this library, since the same phrase (a station name, a platform number) gets reused across announcements.

Naming convention: before uploading, rename every MP3 to match its announcement code, in the form XXX_en.mp3 — the code from the table below, followed by the language suffix. Example: a clip coded PLT-CHG is uploaded as PLT-CHG_en.mp3. The _en suffix leaves room to add the same clip in another language later under the same code. Files that don't match are flagged below so they can be renamed and re-uploaded.
